# Analytics and consent

GA4 is optional. Set `NEXT_PUBLIC_GA_MEASUREMENT_ID` only after the property and legal basis are approved. The tag is not rendered until the visitor selects “Allow analytics”; rejecting analytics leaves the site fully usable. The choice is stored locally and can be reopened from the footer.

Do not add ad pixels, session replay, Tag Manager or Consent Mode without a fresh privacy review. Lead source URL, referrer and approved UTM fields are stored with the enquiry when Supabase is configured.
